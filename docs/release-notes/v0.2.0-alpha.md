# Chiller 0.2.0 alpha

Shaping: you can now tell Chiller where to work harder and where to leave the sound alone, and save your own presets.

## Bands

Six bell-shaped bands sit on the Explain view's spectrum, like Soothe's sensitivity nodes. Each one makes the processing
stronger or weaker around its frequency.

| Do this | What happens |
| --- | --- |
| Double-click an empty spot in the spectrum | Adds a band there (up to six) |
| Drag a node left / right | Moves its frequency |
| Drag a node up / down | Depth: up to +100 % (green, stronger), down to -100 % (purple, weaker) |
| Mouse wheel over a node (Ctrl = fine) | Width, 0.1 to 4 octaves |
| Double-click a node | Depth back to 0 % |
| Right-click a node | Removes the band |

- **Negative depth** scales the cut down: -50 % halves it, -100 % switches the processing off at the band's centre. Use it
  to protect a vocal's presence, the snap of a snare or the air of a mix.
- **Positive depth** makes the detector up to 6 dB more sensitive there (the dashed expected curve drops to show it) and
  the cut up to 1.5 times deeper, even past Max Cut. Use it to chase a resonance the global settings miss.
- Overlapping bands combine. The curve through the nodes shows the result: above the centre line is stronger, below is weaker.
- Bands are host parameters (`band1_on`, `band1_freq`, `band1_depth`, `band1_width`, ... `band6_*`), so they can be automated,
  and they are part of presets, undo/redo and A/B. Factory presets switch them off.
- With every band off (the default), the sound is exactly the same as 0.1.

## User presets

- **Save preset...** in the preset menu stores the current detection, speed, protection and band settings as a JSON file in
  `Documents/Chiller/Presets` (the community preset format, see CONTRIBUTING.md). Saving with an existing name replaces it.
- User presets appear in the preset menu under **User**, and the arrows step through factory and user presets.
- **Open presets folder** shows the folder, so you can share, rename or delete files. Files added there appear within a few seconds.
- Like factory presets, user presets leave Mode, stereo mode, sidechain key, Delta and the output section as they are.

## Also

- LEARN waits for the host transport: press it while stopped (WAITING), it listens when you press play, pauses while stopped
  (PAUSED), and cancels when pressed again.
