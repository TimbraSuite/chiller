# Chiller 0.1.0 alpha

The first version that actually suppresses resonances. This is an **alpha**: the engine and the controls work, the
sound is still being tuned, and a few things are missing (see below). Please try it on your own material and report
what you hear.

## What works

- **Resonance suppression** with a per-bin detector: the spectrum of each frame is compared with an *expected curve*
  (a robust, smoothed version of itself, `Focus` wide). Everything that sticks out by more than `Threshold` is cut by
  `Amount` of its excess, never more than `Max Cut`, and never more than the `Budget` allows on average.
- **Three modes**, all with exactly reported latency (the host compensates it):
  | Mode | STFT | Latency @ 48 kHz | Use |
  | --- | --- | --- | --- |
  | Live (low latency) | 256 | 5.3 ms | tracking, quick checks |
  | Mix | 1024 | 21.3 ms | tracks and buses |
  | Master | 4096 | 85.3 ms | finest resolution, final bounce |
  (the sizes scale with the sample rate: 44.1 / 48 / 96 kHz are tested)
- **Speed**: Attack, Release and Tilt (positive tilt = faster highs).
- **Protect**: *Harmonic Protect* (finds the pitch and spares its harmonics; shown as purple ticks), *Transient Pass*
  (backs off during note and drum attacks), *Budget* (limits the mean reduction between 200 Hz and 16 kHz).
- **Range**: drag the LC / HC square nodes in the Explain view to limit the band that is processed.
- **Stereo**: L/R or M/S processing, with `Link` blending shared and per-channel detection.
- **Sidechain key**: detect from the sidechain input and cut the main signal (switch on in the Explain view).
- **Output**: Mix (latency-compensated dry), Trim (level of the processed signal), Output, Delta (listen to what is
  removed), Auto-gain (makes up the removed energy, at most +6 dB), soft Bypass.
- **Explain view**: input spectrum, expected curve, the cut hanging from the 0 dB line, labelled peaks, harmonic ticks,
  key curve, hover readout (Hz and note), and a 20 s HISTORY heat map. Right strip: harshness in/out, average reduction vs
  budget.
- **Top bar**: six factory presets, A/B compare with copy, undo/redo, LEARN (listens for 3 s and sets Threshold and
  Amount), CPU and latency readouts, output meter.
- Formats: VST3 (Windows, macOS, Linux), Audio Unit (macOS), CLAP, LV2 (Linux), Standalone.

## What is missing or rough

- No band nodes / per-band overrides yet (planned for 0.2). The Range nodes are the only frequency control.
- Harmonic Protect needs enough frequency resolution: it is reliable in Master mode, partly in Mix mode for pitches
  above roughly 250 Hz, and switched off in Live mode.
- Live mode is the same algorithm with a short window, so its low-frequency resolution is coarse (187 Hz per bin).
- LEARN is simple: it sets Threshold and Amount from the average excess; it does not place bands.
- A/B slots, undo history and presets are not saved in the project (the parameters are).
- User presets (Save) are not implemented yet; the preset menu lists the factory presets only.
- The binaries are not code-signed or notarized.
- Tested on Linux with pluginval (strictness 5) and clap-validator; Windows and macOS builds come from CI and have had
  no hands-on host testing yet. Ableton Live is the primary target, please report anything odd.

## Install

Download the zip for your system from the GitHub Actions run (artifact `chiller-windows` / `chiller-macos`) or from the
release page, then:

**Windows**
1. Copy the whole folder `Chiller.vst3` to `C:\Program Files\Common Files\VST3\` (administrator rights needed).
2. SmartScreen may warn on the standalone app: "More info" then "Run anyway".

**macOS** (VST3 and Audio Unit, Apple Silicon and Intel)
1. Copy `Chiller.vst3` to `~/Library/Audio/Plug-Ins/VST3/` and `Chiller.component` to `~/Library/Audio/Plug-Ins/Components/`.
2. The builds are unsigned, so macOS quarantines them after a browser download. Run once in Terminal, then restart the DAW:
   `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Chiller.vst3 ~/Library/Audio/Plug-Ins/Components/Chiller.component`
   (or use the one-line installer in `INSTALL.txt`, which avoids the quarantine).

**Ableton Live**
1. Preferences > Plug-ins: switch on "Use VST3 Plug-in System Folders" (macOS: also "Use Audio Units"), then press Rescan.
2. Find Chiller under Plug-ins > Effects (manufacturer Neuroforge) and drop it on a track.
3. For the sidechain key, choose the source track in the plug-in's sidechain chooser, then switch on "Sidechain key".

## Quick start

1. Put Chiller on a bright vocal, guitar or the mix bus, mode Mix.
2. Press LEARN while the loudest part plays, or lower Threshold until the green cut appears over the harsh peaks.
3. Use Delta to hear exactly what is removed; set Amount and Max Cut until it only removes ringing, not body.
4. Turn on Harmonic Protect (Master mode) for pitched material, Transient Pass for drums.
